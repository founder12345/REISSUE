# Future AI integration

The catalogue, PostgreSQL search, campaigns and moderation work without an AI service. The repository contains no runtime AI integration.

1. Add image identification behind a separate provider contract. Store image provenance and consent separately from model outputs. Return candidate archive records.
2. Evaluate semantic retrieval against a judged archive dataset. Blend candidate sources only after demonstrating that exact identifiers remain dominant and deterministic search remains available.
3. Present catalogue enrichment and duplicate suggestions as reviewable drafts with evidence links. Moderators retain publication and verification authority.
4. Explore opt-in recommendations and aggregated demand forecasting after sufficient real activity exists. Keep projections separate from observed demand and never treat stated interest as a purchase.
